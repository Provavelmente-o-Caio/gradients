# Gradient Estimation

  The calculation of analytical gradients in parameterized quantum circuits is an essential tool for optimizing variational quantum algorithms, allowing for the efficient evaluation of cost function derivatives with respect to circuit parameters. This work studies, implements, and evaluates algorithms for calculating analytical gradients using the Ket platform, which provides support for simulating quantum algorithms on classical hardware. The adopted methodology involves studying the main quantum differentiation methods found in the scientific literature, with a focus on Parameter Shift Rule and Hadamard Test algorithms, and then implementing them, validating through the comparison between analytically calculated gradients and those obtained by implementing the algorithms. The work provides a theoretical and practical basis for studying algorithms for gradient calculation in quantum computing, providing a comparison between the main existing methods and their practical applications.
